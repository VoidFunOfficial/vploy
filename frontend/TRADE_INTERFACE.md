# 交易界面功能说明

## 概述

交易界面用于展示和管理待交易任务，提供优雅的可视化界面来审核AI分析结果和交易决策。

## 主要功能

### 1. 待交易任务展示

展示所有处于 `trade` 阶段且状态为 `waiting` 的任务，包含：

- **市场问题**：清晰展示预测市场的问题
- **概率对比**：并排对比 YES 和 NO 两个方向
  - 市场当前概率
  - AI预测概率
  - 差值（预测 - 市场）
  - 差值颜色编码：
    - 绿色：正差值（AI预测高于市场）
    - 红色：负差值（AI预测低于市场）
    - 深色：差值绝对值 > 5%
- **交易操作**：在对应的 YES/NO 列下显示
  - 买入操作和金额
  - 或"不交易"标记
- **交易详情**：
  - 交易方向（YES/NO）
  - 投入金额
  - 购买份额
  - 成本百分比
  - 仓位占比
  - Kelly评分
- **市场信息**：
  - 市场ID
  - 流动性
  - 交易量
  - 风险因子
- **AI分析理由**：
  - 支持理由（绿色边框）
  - 反对理由（红色边框）

### 2. 已完成交易

以紧凑形式展示已完成的交易任务：
- 任务ID
- 交易方向徽章
- 投入金额
- 市场问题
- 完成时间

## 数据结构

### 任务元数据 (metadata)

```javascript
{
  "market": {
    "id": "898671",
    "question": "Thailand x Cambodia declare war by Dec 31?",
    "outcome_prices": "[\"0.034\", \"0.966\"]",
    "liquidity": "8919.21362",
    "volume": "5760.94729",
    "end_date": "2025-12-31T00:00:00Z"
  },
  "analysis": {
    "p": 0.05,      // AI预测YES概率
    "n": 0.95,      // AI预测NO概率
    "a": 0.7,       // 风险因子
    "reasons_y": ["支持理由1", "支持理由2"],
    "reasons_n": ["反对理由1", "反对理由2"]
  },
  "marks": ["标签1", "标签2"]
}
```

### 任务结果 (result)

```javascript
{
  "decision": "trade",  // 或 "skip"
  "allocation": {
    "side": "YES",      // 或 "NO"
    "dollars": 0.58,    // 投入金额
    "shares": 17.05,    // 购买份额
    "cost": 0.034,      // 成本（价格）
    "fraction_of_gross": 0.0058,  // 仓位占比
    "score": 0.0058     // Kelly评分
  },
  "wealth": 100,
  "locked_value": 0
}
```

## API接口

### 获取待交易任务

```
GET /api/tasks/trade/pending
```

返回：
```json
{
  "success": true,
  "data": {
    "tasks": [...],
    "total": 5
  }
}
```

### 获取已完成交易

```
GET /api/tasks/?stage=trade&status=finished&limit=50
```

## 设计特点

1. **简约美学**：遵循宝塔面板风格，无渐变、无动画
2. **信息密度**：在有限空间内展示最关键信息
3. **视觉层次**：通过颜色、字重、间距建立清晰的信息层次
4. **对比突出**：市场概率 vs AI预测的差值用颜色编码
5. **操作明确**：交易操作直接显示在对应的YES/NO下方
6. **响应式**：支持不同屏幕尺寸

## 颜色方案

- **主色调**：绿色 (#20a53a) - 主要操作按钮
- **YES方向**：绿色 (#4caf50)
- **NO方向**：红色 (#f44336)
- **已完成**：蓝色 (#2196f3)
- **正差值**：绿色系
- **负差值**：红色系
- **中性**：灰色系

## 使用方法

1. 点击"刷新列表"加载最新的待交易任务
2. 查看每个任务的概率对比和AI分析
3. 确认交易决策和投入金额
4. 在已完成交易区域查看历史记录
